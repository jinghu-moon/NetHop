让文字有分寸，
让留白会呼吸。

类型阶、间距、圆角与组件尺寸全部由固定数值刻度生成，组件不得随意取值。中文界面字距统一为 0，层级由字重承担而非字距；间距对齐 4dp 基线网格，保证跨设备像素级一致；一切可点击元素不小于 48×48dp。与《组件配色设计》共用同一套语义表面与文字 Token。

刻度驱动类型阶、间距、圆角均来自固定数值刻度
4dp 基线网格所有间距与尺寸对齐 4 的倍数
中文优先排版字距统一为 0，字重承担层级
触控优先可点击元素不小于 48×48dp

类型阶 Type Scale

改编自 Material 3 的 15 角色类型阶，按信息密度向下收紧一档；字重沿用既有的 620 / 650 / 660 / 670 语汇。点击任意规格可复制 CSS 变量。

为什么需要这份刻度审计《02-组件配色设计》发现其中散落着 19 种不同字号、9 种不同圆角，均为搭建过程中随手取值，没有统一刻度。这份文档定义的刻度将作为后续收紧 02 文档取值的依据。

间距 Spacing

4dp 基线网格，11 级刻度。点击色条可复制变量。“边距”取页面/卡片级别的大间距档位，“间距”取元素之间的小间距档位，二者共用同一套刻度。

圆角 Radius

7 级刻度，从锐角到全圆角。播放画面本身及全屏内容使用 radius-none，不裁切视频画面。

布局网格 Layout Grid

软件是移动端（手机）应用，不做平板 / 折叠屏 / 桌面端的窗口尺寸分级。除播放页外的所有页面锁定竖屏，媒体网格列数只随手机自身宽度做小幅调整。

前提：仅手机，不适配平板上一版按 Material 3 窗口尺寸分级（Compact / Medium / Expanded）设计，隐含了平板、折叠屏展开等大屏场景——这些不是影里的目标设备。真正需要处理的横竖屏切换，只发生在同一部手机上：浏览页面锁定竖屏，播放页允许横屏全屏播放，这是本节唯一的布局分歧点。

组件尺寸 Component Sizing

触控目标最小 48×48dp，是 Android 无障碍基线，也是本套系统里除密集列表外几乎所有可点击元素的默认高度。

图标 Icon Sizes

5 级刻度，24dp 为工具栏与按钮默认尺寸，与既有组件里 Tabler 图标的实际使用尺寸一致。

动效 Motion

时长与缓动曲线的最小集合，供状态切换、展开折叠与页面转场使用。悬停下方色块查看两种缓动的区别。
